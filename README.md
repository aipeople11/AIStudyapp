# 🇫🇷 French Class 8 - Authorized Study Guide

> **🔒 Secure Access Only**  
> This repository contains a highly secure, client-side AES-256 encrypted web portal for accessing the French Class 8 Study Guide. 

## 📖 About
This portal was developed to provide students with a premium, interactive study experience while ensuring the intellectual property and curriculum materials remain strictly protected.

Because the document contains proprietary educational formatting, the actual plaintext content is **not** stored anywhere in this repository. 

## 🛡️ Security Architecture
This project utilizes military-grade **AES-256 Client-Side Encryption** via `crypto-js`.
* **Zero Plaintext:** The source code contains only cipher-text (gibberish). You cannot bypass the lock by viewing the page source or manipulating CSS via Chrome DevTools.
* **No Server/Database:** The decryption happens entirely in the browser's memory using the credentials provided at login.
* **Instant Re-render:** Upon successful decryption, the DOM is completely erased and re-rendered with the plaintext study guide, ensuring smooth performance.
